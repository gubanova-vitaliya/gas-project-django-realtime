# Адаптивный дизайн

Проект использует адаптивный дизайн для корректного отображения на всех устройствах.

## Используемые технологии

- **Flexbox** - для гибкой компоновки элементов
- **CSS Grid** - для сложных макетов
- **Media Queries** - для адаптации под разные размеры экранов

## Брейкпоинты

Проект использует следующие брейкпоинты:

- **Desktop**: > 768px
- **Tablet**: ≤ 768px
- **Mobile**: ≤ 480px

## Компоненты

### Навигация (Navbar)

Навигация использует Bootstrap Navbar с встроенной адаптивностью:

- **Desktop**: Полная навигация с горизонтальным меню
- **Tablet/Mobile**: Бургер-меню с выпадающим списком ссылок

**Особенности:**
- Автоматическое переключение на бургер-меню при ширине ≤ 768px
- Плавные переходы и анимации
- Улучшенные стили для мобильных устройств

### Карточки газов (GasCard)

Карточки используют flexbox для адаптивной компоновки:

```css
.grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.gas-card {
  flex: 1 1 300px; /* Минимальная ширина 300px */
}
```

**Поведение:**
- **Desktop (> 768px)**: 3-4 карточки в ряд (зависит от ширины экрана)
- **Tablet (≤ 768px)**: 2 карточки в ряд, минимальная ширина 280px
- **Mobile (≤ 480px)**: 1 карточка в ряд, вертикальная компоновка

**На мобильных устройствах:**
- Карточки занимают всю ширину экрана
- Изображение сверху, информация снизу
- Улучшенные отступы и размеры шрифтов

### Страница деталей газа (GasDetailPage)

Адаптивная компоновка свойств газа:

- **Desktop**: Свойства в 2 колонки (grid)
- **Tablet/Mobile**: Свойства в 1 колонку

**Особенности:**
- Адаптивные размеры изображений
- Гибкая компоновка свойств
- Оптимизированные отступы для мобильных

### Главная страница (HomePage)

- Полностью адаптивное изображение
- Центрирование контента на всех устройствах
- Оптимизированные отступы

## Примеры использования

### Flexbox для списка карточек

```css
.cards-wrapper {
  display: flex;
  justify-content: space-between;
  align-items: stretch;
  flex-wrap: wrap;
  gap: 20px;
}

.card-item {
  flex: 1 1 300px; /* Минимальная ширина для переноса */
  padding: 15px;
}
```

### Media Queries

```css
/* Планшеты */
@media (max-width: 768px) {
  .card-item {
    flex: 1 1 280px;
    padding: 12px;
  }
}

/* Мобильные устройства */
@media (max-width: 480px) {
  .card-item {
    flex: 1 1 100%;
    flex-direction: column;
  }
}
```

## Рекомендации

1. **Всегда используйте относительные единицы** (rem, em, %, vw, vh) вместо фиксированных пикселей где возможно
2. **Тестируйте на реальных устройствах** - эмуляторы не всегда точно воспроизводят поведение
3. **Используйте flexbox для простых макетов** - он проще и гибче чем grid для большинства случаев
4. **Проверяйте touch-цели** - на мобильных устройствах кнопки должны быть минимум 44x44px
5. **Оптимизируйте изображения** - используйте `loading="lazy"` и адаптивные размеры

## Проверка адаптивности

### В браузере

1. Откройте DevTools (F12)
2. Нажмите Ctrl+Shift+M (или кнопку переключения устройства)
3. Выберите устройство или установите кастомный размер
4. Проверьте все страницы на разных размерах

### Рекомендуемые размеры для тестирования

- **Mobile Small**: 320px
- **Mobile Medium**: 375px
- **Mobile Large**: 425px
- **Tablet**: 768px
- **Desktop**: 1024px, 1280px, 1920px

## Известные особенности

- Bootstrap Navbar автоматически переключается на бургер-меню при ширине ≤ 992px (lg breakpoint)
- Карточки газов переносятся на новую строку при ширине < 300px
- На мобильных устройствах карточки используют вертикальную компоновку для лучшей читаемости
